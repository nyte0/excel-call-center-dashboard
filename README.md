#Call Centre Performance Dashboard (2023)

##Project Overview

An interactive Call Centre Performance Dashboard created using Microsoft Excel to analyse call centre activities, customer ratings and representative performance throughout 2023.

##Key Metrics

- Total Calls
- Total Amount
- Total Duration
- Average Customer Rating
- Happy Callers

##Dashboard Analysis

- Monthly Call Trends
- Day-wise Call Distribution
- Female vs. Male Caller Comparison across Cities
- Customer Rating Distribution
- Representative-wise Call and Amount Analysis
- City-wise Performance Breakdown

##Tools & Excel Features

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers for Interactive Filtering
- Conditional Formatting
- KPI Cards
- Dashboard Visualisation

##Project Objective

To organise and analyse call centre data, identify performance patterns and present key business metrics through an interactive Excel dashboard.
